# Demo Techista Pro

Landing page estática para servicios de techista, con diseño responsive, gráficos SVG animados y publicación en GitHub Pages.

## Desarrollo

Abrir `index.html` en un navegador o iniciar un servidor estático desde la raíz del repositorio.

## Publicación

El workflow de GitHub Actions publica el sitio en Pages cuando se actualiza la rama `main`.

## Imágenes de trabajos

Las fotos de la galería se guardan localmente en `images/works/` para evitar dependencias de hotlink. Sus archivos originales proceden de ABC Supply, Techista Construcciones y Home Solution.
