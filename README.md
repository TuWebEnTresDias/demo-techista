# Demo Techista Pro

Landing page estática para servicios de techista, con diseño responsive, una foto de campaña generada para la demo y un GIF animado sincronizado con el scroll. Se publica en GitHub Pages.

## Desarrollo

Abrir `index.html` en un navegador o iniciar un servidor estático desde la raíz del repositorio.

## Publicación

El workflow de GitHub Actions publica el sitio en Pages cuando se actualiza la rama `main`.

## Imágenes de trabajos

La secuencia principal usa una imagen de campaña original (`images/roof-repair-still.jpg`) y un GIF en loop (`images/roof-repair-motion.gif`). Las fotos de la galería se guardan localmente en `images/works/`; proceden de ABC Supply, Techista Construcciones y Home Solution.
